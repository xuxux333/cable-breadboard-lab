# v0.3.1 核查意见处理说明

核查基线为 v0.3.0。以下区分软件缺陷、浏览器相关疑点和需要实物确认的条件；不把文字核查等同于实物验收。

## 已核实并修复的软件问题

| 问题 | 处理 |
| --- | --- |
| 导入 ID 注入 SVG 属性 | 旧版已在 Chrome 离线页面复现事件执行；新版本限制 ID、统一属性转义，并校验文本与引脚映射。 |
| SVG 导出包含编辑状态 | 移除选中框、A/B 浮层、探针、冲突与内部导通辅助层，恢复全部导线不透明度，内嵌所需样式。 |
| 仅首脚吸附与非法旋转 | 搜索所有脚均能入孔的位置；双排器件要求各脚落在独立导通组，仅允许 0°/180°，无法放置时保持有效位置。 |
| 改标号使时钟误报 | 时钟按器件类型与物理端点连通判断，显示标号不再作为身份。 |
| 非规范 pin 字符串产生幻影节点 | 整数和规范十进制字符串可用；拒绝 `01`、`1.0`、空格等含糊写法，失效端点明确报错。 |
| 重名、过长字段及过多折点 | 导入、属性编辑和新增对象使用一致边界，避免应用生成无法重载的方案。 |
| 未使用且不一致的参考数据 | 移至 `docs/circuit-reference.json`，补拨码引脚和电源端、统一 LED 与电阻端点；增加与默认方案逐网对照测试。 |
| 离线品牌链接失效 | 品牌改为静态标识，构建拒绝残留的相对导航和外部加载资源。 |
| 浏览器快捷键被截获 | 普通编辑器快捷键跳过 Ctrl/Cmd/Alt；保留应用自己的撤销/重做。 |
| 触屏无法平移与缩放 | 空白处单指平移、双指缩放；器件属性栏延迟到点按结束展开，避免挡住第二触点。 |
| 孔阵区域无法添加折点 | 缩小孔心命中范围，并支持 Alt 点击强制设置绝缘折点。 |
| 损坏存档被静默覆盖 | 备份原始文本、保护原键、持续显示错误并提供备份恢复；备份限额兼容旧键。保存失败时明确提示导出。 |

此外补充关闭/切后台时保存、拖拽取消和删除安全、标准双击编辑、模态焦点恢复、标签方向键操作、图层外点关闭，以及关键说明文字的字号与对比度。

“修改属性后立即点画布会丢失输入”在本次 Chrome 基线测试中没有复现。新版本仍增加显式提交事务，在选择变化前保存输入，不把该疑点记录成已经证实的旧版故障。

## 构建与发包

- 测试自动发现限定为 `tests/`，避免遗漏新测试或误执行临时审计脚本。
- 版本号读取 `package.json`；源码与构建统一 LF，测试验证 LF/CRLF 检出产物相同。
- `npm run release` 生成带顶层目录的确定性 ZIP、离线 HTML 和 SHA256 清单；仅生成本地文件。
- CI 配置覆盖 Windows/Linux，上传构建产物；本地通过不代表尚未运行的远程 CI 已通过。

## 原厂资料复核及保留的实物条件

1. **ADC0804 VREF/2 悬空不等于接错。** TI 手册 §9.2.1.2.3.1 允许使用 VCC/2 内部参考；目前按 5 V 供电与约 0–5 V 量程规划，仍需用已知输入电压检查实物量程。
2. **ADC 自时钟保持原接法。** 10 kΩ 电阻跨 4/19 脚，150 pF 电容由 4 脚 CLK IN 到地，依据 TI Figure 35。
3. **NE555 的“典型 3.3 V”不是 FPGA 兼容保证。** 手册数据带特定负载条件，不能当作轻载输出上限。时钟、ADC 数据和 CD4511 输入门限分别核对。
4. **数码管沿用课程确认接法。** 3、8 脚各串独立 1 kΩ 接地；4511 到 a–g 直接连接。没有擅自改回每段限流。
5. **拨码 OFF 偏置必须先落实。** 软件不会把开路默认视为低电平，也没有自动添加未经确认的电阻。C392 其余段脚、真实 FPGA 接口及 GL-48 铜片结构仍需实测。
6. **电源轨标记不表示已经供电。** 默认未使用第五组竖轨和顶部电源条；接线柱与轨道之间也需要显式跳线。

来源：[TI ADC0804-N](https://www.ti.com/lit/ds/symlink/adc0804-n.pdf)、[TI NE555](https://www.ti.com/lit/ds/symlink/ne555.pdf)。

## 仍保留的范围限制

首次生成参考布局仍会执行自动避让。该版本未重写全部紧凑源码格式，也未实现完整的仅键盘布线、屏幕阅读器编辑或通过正式 WCAG 验收。当前几何与导通检查不验证模拟电平、偏置、三维线高、线束拥挤或实物通电安全。
